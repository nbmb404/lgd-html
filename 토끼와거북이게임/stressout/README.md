# 와장창

승패와 제한 시간 없이 화면 속 물건을 부수며 잠깐 기분을 전환하는 웹 게임입니다.

## 기술 스택

- TypeScript
- React
- Express.js
- SQLite

## 실행

```bash
pnpm install
pnpm dev
```

개발 서버는 React `http://127.0.0.1:5173`, Express API `http://127.0.0.1:4000`으로 실행됩니다.

## 과제 시연 흐름

1. 시작 화면에서 `마음껏 부수기`를 누릅니다.
2. 물건을 클릭하거나 드래그해서 완전히 부숩니다.
3. `엔돌핀 +10`과 누적 엔돌핀 증가를 확인합니다.
4. 설정을 바꾼 뒤 새로고침해 저장 여부를 확인합니다.
5. 이용 기록에서 세션 기록과 삭제 API를 확인합니다.
